# Short-term-rental source update — 2026-11-03

On 28 October 2026 the public Planning web map replaced its short-term-rental
layers with `Licensed_Short_Term_Rentals` (item `6228c943…`, "42 licensed
parcels as of 2026-10-28"). The licensing page still screened against
`Short_Term_Rentals_June_2026`, which stayed public and kept answering, so the
page worked but no longer matched the map. The weekly live-service monitor
caught it on 2 November as contract drift: `public-web-map-parity` failed for
`business-rental` and `business-buffer`.

`business-licensing.html` now reads `Licensed_Short_Term_Rentals/0` and `/1`.
The new service has the same 42 parcels, keeps `parcel_id`, and keeps
`BUFF_DIST` at 121.92 (400 feet stored in metres, as before), so the
screening logic does not change. It drops 54 fields of the old service,
among them owner name, mailing address and tax values; this page never read
them. What a reader sees changes only in its date: the lede, the first flag
and the copied source line now say October 2026 instead of June 2026.
`DATA-SOURCES.md`, `README.md`, `USAGE.md` and `WEB-MAP-REVIEW.md` name the
new service.

Found, not acted on here: the old `Short_Term_Rentals_June_2026` service is
still public and still exposes owner names and mailing addresses for the 42
parcels. Unsharing it is an ArcGIS Online step for its owner, once this
release is in production.
